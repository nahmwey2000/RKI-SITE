# RKI site. ideas

Next things, roughly smallest first. One at a time, and only if it still
feels like him.

## Small

- **The hero video.** The old site opened on a clip. Get the mp4 and run it
  through the same shader as the still (same code path, a video texture
  instead of an image one).
- **Tour dates.** A line under the ticker, or a fifth section if there are
  more than two. Nothing worse than an empty "tour" page.
- **Newsletter.** The old site had SUBSCRIBE. If there is a provider (Mailchimp,
  Beehiiv, Laylo), add a single field next to CONTACT.
- **Merch.** One link in the nav if there is a store. Do not build a store here.
- **Share image.** A proper og:image (the mark over a still) so links look
  right in texts.

## Medium

- **Archive 004 and up.** The section is built for a growing list. Each one
  wants a real note in his voice, not a description.
- **Lyrics, one song at a time.** A single page per release, quiet, black,
  lyrics and credits. Only worth it if he wants to write them out.
- **Visualizer loops.** The reels are the best thing on the IG. Self-host two
  or three short loops and use one as the hero.

## Bigger

- **Unlock that remembers.** Archive files stay open for a returning visitor,
  and a new file announces itself in the ticker.
- **Sound on the page.** A five second bed under the hero, off by default, one
  small toggle. Only if it is mixed properly.
